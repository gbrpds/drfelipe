# Fotos do Dr. Felipe Benthien

Suba aqui as fotos originais do Dr. Felipe (JPG, PNG ou WEBP, de preferência na maior resolução disponível).

Sugestão de nomes, para facilitar o uso no site:

- `retrato-*.jpg` — retratos de jaleco, fundo neutro
- `consultorio-*.jpg` — no consultório, com ou sem paciente
- `exame-*.jpg` — polissonografia, equipamentos, sala de exame
- `hospital-*.jpg` — hospital, UTI, equipe
- `comunidade-*.jpg` — encontros do Reset do Sono, academia, eventos
- `pessoal-*.jpg` — família, música, atividade física (uso opcional)

As imagens são otimizadas e copiadas para `assets/img/` quando entram no site.
Fotos de pacientes só com autorização por escrito.
